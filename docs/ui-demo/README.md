独立静态前端原型，覆盖用户端五 Tab、模拟登录、识草／OCR、资料、问答、社区、消息、个人中心和情景视频。不连接项目后端；仅供界面与交互参考，不代表小程序或后台功能已交付。

推荐双击 `demo.html` 在浏览器打开，这是包含全部样式、脚本和插画的单文件版本，可以直接复制给别人体验，无需安装依赖或启动服务器。

`dist/index.html` 是分文件版本，方便后续修改。顶部“手机预览”可切换为接近小程序的窄屏布局。

也可从此目录启动静态预览：

```powershell
python -m http.server 8765 --bind 127.0.0.1 --directory dist
```

浏览器打开 http://127.0.0.1:8765。服务器仅提供静态文件，不是业务后端。
