# 近重复排除规则（GY-I20）

> 依据第6.1节："同一原图裁剪、连拍或近重复不能同时进入训练与测试"；"记录来源、对象标注、质量、答案及已知使用状态"。

## 1 目标

防止**同源裁剪／连拍／近重复**样本同时落入训练（调参）与最终测试，导致测试集泄漏、指标虚高。本规则在样本索引层面以 `clusterId` 表达"同源"，并由校验器强制同簇同 split。

## 2 同源定义

| 类型 | 判定 | 索引表达 |
| --- | --- | --- |
| 同源裁剪 | 同一原图的不同裁剪/缩放/旋转 | 同一 `clusterId` |
| 连拍 | 同一设备同一时段的连续帧 | 同一 `clusterId` + 同一 `captureSeriesId` |
| 近重复（图像） | 感知哈希汉明距离 ≤ 阈值（默认 8） | 应同 `clusterId` |
| 近重复（文本） | 同 task 标准答案文本完全相同 | 应同 split |

## 3 强制规则（校验器会阻断）

1. **同簇不跨 split**：一个 `clusterId` 下所有样本的 `split` 必须唯一。
2. **连拍不跨簇、不跨 split**：`captureSeriesId` 只能映射到一个 `clusterId` 与一个 `split`。
3. **感知近重复需同簇**：汉明距离 ≤ 阈值的两条样本若不同簇，报错要求合并或人工确认。
4. **文本近重复不跨 split**：问答/ASR 同文本样本必须同 split。

命令：

```bash
node tools/evaluation/validate-evaluation-samples.mjs --index <index.json> --hamming 8
```

## 4 每类与拒识样本记录

- **每类**：`labelClass` 记录具体类别；报告逐类指标（`perClass`），不合并掩盖。
- **拒识**：`expectation=reject` 标注期望拒识样本；拍草覆盖内拒识计入未命中；覆盖外/低质量拒识是期望行为。
- 近重复簇成员数、被排除数、各质量/覆盖分组计数由评估命令输出到报告的 `gaps` 与支持统计中。

## 5 操作流程

1. 采集原始样本（仓库外私有存储），计算 `contentSha256` 与（图像）`perceptualHash`。
2. 人工/工具标注同源关系，生成 `clusterId`（同源裁剪与连拍必须合并到同簇）。
3. 运行校验命令，确认无跨 split 泄漏。
4. **先冻结**测试集（写入 `frozenIndexVersion`），再进行模型调参。
5. 冻结清单、来源、划分与评估口径**先经监工审查**，再据以运行评估。

## 6 与"不得虚构样本"的关系

- 近重复排除**不允许**用"裁剪/连拍冒充独立样本"来凑样本数量；同源样本只计入一次独立证据。
- 不得用生成/演示/重复媒体冒充真实评估样本；合成占位输入仅在 `dataKind=synthetic_placeholder` 下验证程序，恒不产生达标结论。
