## 原契约的实际缺口

原 OpenAPI 有 JSON 上传授权、完成声明、媒体元数据、删除与访问授权，没有上传实际字节或 owner 内容读取路径。既有 ESM 服务生成两个示例 URL，仍为内存参考服务，不能据此声称 HTTP 已实现。PR60 的最终已审 SHA `11425650c1852b49d2068604a1274d37b72a05ee` 覆盖类型、时长、EXIF、幂等及边界修复，不能替代真实传输和持久化证据。

本次在 `/api/v1` 下新增：

| operationId | 路径 | 请求／响应 |
| --- | --- | --- |
| receivePrivateMediaBytes | `PUT /media/uploads/{id}/content` | 二进制实体；`Content-Length`、`Idempotency-Key`、`If-Match`、用户会话及 `X-Media-Access-Token`；200 `MediaEnvelope`、当前 ETag、no-store |
| readOwnerMediaContent | `GET /media/{id}/content` | 用户会话及 `X-Media-Access-Token`；200 受控二进制、当前 ETag、no-store |

两个 URL 从现有 `UploadGrant.upload`／`AccessGrant` 获取，不增加 DTO 字段。token 不放查询参数、日志或原桶 URL，不重定向私有文件。上传实体的 Content-Type 使用既有 UploadInput MIME 集合，长度与实际计数须匹配初始化声明并受用途上限约束；合法接收不意味着完成验证、ready、AI 调用或社区公开。

## 后续 HTTP 实现必须落实的行为

句柄最长 300 秒，绑定服务端 owner、同一 session/auth_epoch、所需用途的 epoch 快照及媒体 revision；每次读写重查当前权限。原生命周期的 24 小时初始化过期不等于传输句柄时效，当前参考模块示例授权不能当作新端点已达成上述要求。无会话 401，非本人／不存在／旧或失效句柄统一 404。图片只读去元数据衍生件；音频为受控私有对象。社区访问规则和原 JSON 完成／删除语义不改。

首次 PUT 的 If-Match 是授权时媒体 revision，接收后递增并返回新 ETag；complete 使用此新 ETag。原键、原 If-Match、完全相同字节的 PUT 重试回放首次接收结果，回放前仍核对身份、用途、未删除状态及回执与当前媒体的兼容关系；改变字节或请求为 409。同一旧句柄不能在完成、取消、撤回或删除后再制造新对象。完成路径保留独立 JSON 声明与已有真实字节校验，不能把二进制塞进原 complete DTO。

这是兼容的新增操作及操作索引，原 Media/AccessGrant、错误码、枚举和 1.0.0 标识保持；既有消费者无新增必填字段。新消费者须按新增操作及头约定开发。随本 PR 更新 `operations.json`、契约入口和专项消费断言；现有社区／知识定义未改，不增加二月模块。设计检查从 112 个操作变为 114 个操作，不冒充运行实测。

## 本次真正交付的文件适配器

`packages/media/local-store.mjs` 以同步 `put/get/has/delete/size` 兼容现有 store，调用方提供独立、受 OS 权限保护的绝对本地目录。对象仅为不透明随机引用，拒绝路径分隔符、盘符、ADS 和其它非引用输入；禁止 filesystem root 和 UNC 根目录。构造及每次操作核对祖先、根目录身份、symlink/junction；对象须为单链接的普通、有界非空文件，读取同时核对打开文件与路径身份、大小和时间属性。拒绝异常目录及外部放入的陌生文件。写入使用独占创建、逐次计数、fsync；失败尽力只回收本次创建且身份未被替换的文件，不能将“尽力回收”冒充耐久删除任务。

新建 POSIX 目录／文件模式为 0700／0600，既有 POSIX 根目录不能向组／其它用户开放。**Windows 的 mode 不等于 ACL**：必须由运行账户预先保证专用目录 ACL，仅向服务身份和必要管理员开放；本组件没有配置或独立验证 Windows ACL，没有透明文件加密或备份保护。它拒绝观测到的链接和文件替换，仍要求根目录不向其它不可信 OS 主体开放写权限；Node 路径 API 在 Windows 无目录句柄相对打开的完整保证，不承诺抵御拥有该目录写权限的攻击者在任意指令间持续替换祖先。

适配器仅存实际字节，不承担用途、owner 或 MIME 授权；调用方必须复用已审媒体校验和权威服务。文件可跨适配器重新构造保存，本次 `createMediaService` 的媒体状态及幂等仍在内存，不伪称重启后业务状态持久化。对象路径／内容类型不增加到公开投影；本次没有监听端口或暴露静态目录。真实对象及凭据只能放忽略目录，测试仅使用系统临时目录中的明确合成图片／音频，全部自行清理。
