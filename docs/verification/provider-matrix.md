# 服务接入验证矩阵（GY-I25）

本台账用于 `GY-I25 提前验证正式AppID、真机域名及AI和数据库服务接入`。

**核心原则**：资源"声明具备"不等于"已验证"。每项必须有实测证据；测试号、模拟结果、缺失资格必须如实标注，不得冒称可用。

- 分支：原`feature/verify-platform-services` / PR #32；接续`codex/gy-i25-access-verification`
- 关联 issue：#27
- 最后更新：2026-10-04；[来源与实际证据](continuation-evidence.md)

## 1 状态定义

| 状态 | 含义 |
| --- | --- |
| 未验证 | 尚未开始实测 |
| 验证中 | 正在调用或等待账号开通 |
| 已通过 | 成功样例与受控失败样例均有证据 |
| 阻塞 | 缺账号、缺资格、缺设备或资料，明确记录阻塞原因 |
| 不可用 | 实测不满足要求，需替代方案 |
| 用户已确认 | 人类提供账号类型/资源声明，未自动计为技术实测 |
| 工具局部已测 | 实际工具/模拟器结果，不能计手机/业务/供应商成功 |

> 本任务只验证**接入条件**，不替代需求文档第 6 节的准确率与性能验收。
