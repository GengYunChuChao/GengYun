本台账用于 `GY-I25 提前验证正式AppID、真机域名及AI和数据库服务接入`。

## 1 状态定义

| 状态 | 含义 |
| --- | --- |
| 未验证 | 尚未开始实测 |
| 验证中 | 正在调用或等待账号开通 |
| 已通过 | 成功样例与受控失败样例均有证据 |
| 阻塞 | 缺账号、缺资格、缺设备或资料，明确记录阻塞原因 |
| 不可用 | 实测不满足要求，需替代方案 |

> 本任务只验证**接入条件**，不替代需求文档第 6 节的准确率与性能验收。
