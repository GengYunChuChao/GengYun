# 调用额度估算（GY-I25）
依据需求文档与 `GY-I20` 的样本要求，估算六类服务的调用量，供团队申请额度与预算决策使用。

**纪律**：估算仅供申请额度使用；**不擅自开通付费服务**，任何计费开通须团队确认。

---

| 能力 | 需求样本量 | 估调用次数 | 是否可能计费 | 备注 |

| 标签 OCR | 清晰 200（含≥20 登记记录）+ 低质量 100 | 约 300 |  | 按图片张数 |
