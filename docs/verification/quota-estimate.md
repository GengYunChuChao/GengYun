# 调用额度估算（GY-I25）
依据需求文档与 `GY-I20` 的样本要求，估算六类服务的调用量，供团队申请额度与预算决策使用。

**纪律**：估算仅供申请额度使用；**不擅自开通付费服务**，任何计费开通须团队确认。

| 能力 | 需求样本量 | 估调用次数 | 是否可能计费 | 备注 |

| 标签 OCR | 清晰 200（含≥20 登记记录）+ 低质量 100 | 约 300 |  | 按图片张数 |
| 普通话 ASR | 50 段（≥10 人） | 约 50 |  | 按音频条数 |
| 语音合成 TTS | 30 段 | 约 30 |  | 按文本条数 |
| 大模型问答 | 120 题（60 可答 / 20 不足 / 20 危险 / 20 注入） | 约 120 |  | 按请求次数 |
| 文字/图片 AI 筛查 | 风险 200 + 正常 200 | 约 400 |  | 按内容条数 |

上述最低数量算术合计 **1400 次**外部调用。识草覆盖内取max(300,30×承诺类别数)，再加覆盖外100和低质量100；类别超过10时500只是下限。若审核拆文字/图片为两次、ASR异步轮询、重试或回答触发TTS，按实际接口再加量；不是供应商报价或已购额度。
