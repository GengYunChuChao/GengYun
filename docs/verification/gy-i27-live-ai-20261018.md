## 附录 A LLM 单发封装全文（一次性薄封装，未入仓、未接入 CI）

用途：替代 `tools/verify-llm-live.mjs` 自带 `main()`（10 用例、9 次付费发送，含 1.3M token 用例），在「每端点 ≤2 次」下只发 1 条短问；复用 `tools/ai-config.mjs` 的 `prepareOfflineRequest()` 与 `tools/verify-llm-live.mjs` 的 `runCase()`、`priceTokens()`、`USD_PER_TOKEN`、`BUDGET_CEILING_USD`（`CNY_PER_TOKEN` 由 `runCase()` 内部用于折算峰值/空闲档）。密钥只经 `loadPrivateEnvironment()` 进内存，不打印；发送前先落盘预留，ledger 写失败则零发送；`wx` 锁阻断第二次/并发；崩溃留下的锁不自动清理、不自动重试。

```js

// tools/ai-config.mjs prepareOfflineRequest(). The tool's own main() runs a 10-case batch (9 paid sends,
// incl. a 1.3M-token oversize request) and is therefore NOT usable under the dispatch cap (<=2 calls per
// endpoint, 1 short prompt). This runner keeps the same discipline for a single send:
//   * a USD reservation is persisted BEFORE the send; a ledger write failure aborts with ZERO send;
//   * a fresh lock file blocks any second/parallel run (no automatic retry, no resumption);
//   * at most one paid call, cumulative USD ceiling from verify-llm-live.mjs;
//   * the key, headers and identity values are never printed.
import { readFileSync, writeFileSync, existsSync, unlinkSync } from 'node:fs';
import { URL as NURL } from 'node:url';
import { loadPrivateEnvironment, prepareOfflineRequest, providerFor } from '../../../tools/ai-config.mjs';
import { runCase, priceTokens, USD_PER_TOKEN, BUDGET_CEILING_USD } from '../../../tools/verify-llm-live.mjs';

const here = new URL('.', import.meta.url);
const repo = new URL('../../../', here);
const LEDGER = new NURL('llm-ledger.json', here);
const LOCK = new NURL('llm-process.lock', here);
const AUTHORIZATION = 'gy-i27-live-ai-20261018-llm-once';
const MAX_PAID_CALLS = 1;
const PROMPT = '农药标签上的安全间隔期是什么意思？请用一句话回答。';
const round6 = n => Number(n.toFixed(6));

const args = process.argv.slice(2);
if (args.length !== 2 || args[0] !== '--credentials') throw Error('USAGE: --credentials <private file>');

const config = JSON.parse(readFileSync(new URL('docs/verification/config.local.json', repo), 'utf8'));
const env = loadPrivateEnvironment(args[1]);
const p = providerFor(config, 'llm');
if (!env.DEEPSEEK_API_KEY) throw Error('MISSING_CREDENTIALS');
if (Array.from(PROMPT).length > 50) throw Error('PROMPT_TOO_LONG');

const spec = { case: 'gy-i27-single', paid: true, expect: 'content', body: prepareOfflineRequest(config, 'llm', { text: PROMPT }).body,
  estimate: { inputTokens: 60, outputTokens: 128 } };
const estimateUsd = round6(spec.estimate.inputTokens * USD_PER_TOKEN.input + spec.estimate.outputTokens * USD_PER_TOKEN.output);

writeFileSync(LOCK, AUTHORIZATION, { flag: 'wx' }); // a crash leaves the lock: no automatic retry
try {
  const ledger = existsSync(LEDGER) ? JSON.parse(readFileSync(LEDGER, 'utf8')) : { authorization: AUTHORIZATION, ceilingUsd: BUDGET_CEILING_USD, reservedUsd: 0, entries: [] };
  if (ledger.authorization !== AUTHORIZATION) throw Error('LEDGER_AUTHORIZATION_MISMATCH');
  if (ledger.entries.length >= MAX_PAID_CALLS) throw Error('COUNT_LIMIT_REACHED');
  if (ledger.reservedUsd + estimateUsd > BUDGET_CEILING_USD + 1e-9) throw Error('BUDGET_REFUSED');
  const entry = { case: spec.case, paid: true, state: 'OUTCOME_UNKNOWN', estimateUsd, reservedUsd: estimateUsd, httpStatus: null, elapsedMs: null, costUsd: 0, costCnyPeak: 0, costCnyOffPeak: 0 };
  ledger.entries.push(entry);
  ledger.reservedUsd = round6(ledger.reservedUsd + estimateUsd);
  writeFileSync(LEDGER, JSON.stringify(ledger, null, 2)); // persisted BEFORE the send
  const startedAt = new Date().toISOString();
  const r = await runCase(config, env, spec, {}, globalThis.fetch, p.timeoutMs);
  const finishedAt = new Date().toISOString();
  Object.assign(entry, { state: r.state, httpStatus: r.httpStatus, elapsedMs: r.elapsedMs, inputCharacters: r.inputCharacters,
    responseId: r.responseId, model: r.model, finishReason: r.finishReason, contentLength: r.contentLength, contentExcerpt: r.contentExcerpt,
    usage: r.usage, costUsd: r.costUsd, costCnyPeak: r.costCnyPeak, costCnyOffPeak: r.costCnyOffPeak, error: r.error, startedAt, finishedAt });
  writeFileSync(LEDGER, JSON.stringify(ledger, null, 2));
  const preview = r.usage ? priceTokens(r.usage.prompt_tokens, r.usage.completion_tokens) : null;
  console.log(JSON.stringify({ authorization: AUTHORIZATION, endpoint: p.endpoint, requestedModel: p.model, promptCharacters: Array.from(PROMPT).length,
    paidCalls: ledger.entries.length, reservedUsd: ledger.reservedUsd, ceilingUsd: BUDGET_CEILING_USD, pricingPreview: preview, entry }, null, 2));
  process.exitCode = r.state === 'BUSINESS_RESPONSE' ? 0 : 1;
} finally {
  try { unlinkSync(LOCK); } catch { /* already gone */ }
}
```

复现前提（按脚本实际读取的字段）：
1. `docs/verification/config.local.json` 存在，且 `providers.llm` 存在并能过 `tools/ai-config.mjs` 的 `configurationIssues()`（`prepareOfflineRequest()` 第 100 行先调它）：`env==='dev'`、`privacy` 两标志 false、endpoint 白名单、`timeoutMs` 在 1000–20000、`maxRetries===0`、`maxVerificationCalls===2`。`providers.llm` 的实际字段为 `vendor/endpoint/model/apiKeyEnv/timeoutMs/authentication/maxRetries/maxVerificationCalls/maxOutputTokens/stream/thinking/maxTextCharacters` 等；**配置里没有 `llm.allowed` 这个键**（此前表述有误：全仓无代码读 `.allowed`）。
2. 凭据文件（JSON）须含 `appid`（必须等于 `wx4407a4b908a69a54`，否则 `PRIVATE_ACCOUNT_MISMATCH`）与字段 `deepseekApiKey`；`loadPrivateEnvironment()` 按 `ENV_FIELDS`（`tools/ai-config.mjs:14`）把 `deepseekApiKey → DEEPSEEK_API_KEY` 等 10 个字段映射成环境变量（`:21` 校验 appid、`:23` 逐个 `validText` 赋值），脚本只检查映射后的 `env.DEEPSEEK_API_KEY`（第 30 行，缺失即 `MISSING_CREDENTIALS`），不打印值。**凭据文件里不写 `DEEPSEEK_API_KEY` 字面键**——不在 `ENV_FIELDS` 里，写了也不映射，仍会 `MISSING_CREDENTIALS`。
3. `llm-ledger.json` 不存在，或其 `entries.length < MAX_PAID_CALLS(=1)`；`reservedUsd + 预留 ≤ BUDGET_CEILING_USD(=0.1)`。
4. `budget.*`（`liveInferenceAllowed`/`maxVerificationCalls`/`maximumCharge`）**不被该脚本读取**，只参与 `ai-config.mjs:71` 的 `budgetLocked` 审计输出。

脚本内部路径解析与 cwd 无关：第 12、13 行两处相对 `import`、第 16 行 `new URL('../../../', here)` 都以**模块文件**为基准（见 §3 注）；但 `--credentials` 若给**相对路径**，则由 `loadPrivateEnvironment()` 的 `readFileSync` 按**当前目录**解析，只有给绝对路径才与 cwd 无关。脚本位于 `.pg17/tmp/live-ai/` 时三层上溯恰好指向仓库根，挪位置需同步改第 12、13、16 行三处。
