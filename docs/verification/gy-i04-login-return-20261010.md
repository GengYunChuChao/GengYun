## 实际行为

目标仅存在当前小程序进程内，登录成功后消费一次；进程重启不保留。允许实际注册页面，拒绝登录页和外部地址；只有两个资料详情页允许单一 id 参数，按字符和长度校验。非法目标替换并清除旧目标。tab 使用 switchTab；登录成功返回非 tab 使用 reLaunch，清除登录页面栈；正常已鉴权入口使用 navigateTo。

主页入口和受限页仍通过服务端会话核实授权。returnTo 只控制导航，不产生角色或权限。登录失败、取消、离页、账户切换、退出及新入口使旧异步操作失效；旧 wx.login、code 交换、核实、弹窗及导航失败回调不能恢复过时身份或覆盖新目标。既有服务端撤销确认文案保留，游客取消只表示本地会话清除。
