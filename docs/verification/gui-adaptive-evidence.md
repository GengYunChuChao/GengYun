### 3.3 本轮样式改动

`miniprogram/app.wxss` 的 `.page` 底部内边距由 `48rpx` 调整为 `100rpx`：

- 依据：`tabBar` 为 fixed 覆盖层、不占文档流，其高度固定约 50px（100rpx）
- 原值风险：iPhone 上由 `env(safe-area-inset-bottom)`（home indicator 区域，约 34pt）补足，故常见机型不重叠；但 **Android 侧 `safe-area-inset-bottom` 常为 0**，48rpx（24px）不足以避开 50px 的 TabBar，末屏内容存在被压住的风险
- 当前状态：**iOS 模拟器已确认无重叠；Android 未验证**，列入 [GY-I23](https://github.com/Sek1ro-oka/GengYun/issues/23) 真机复测项
- 副作用：iPhone 上底部留白较原值增加约 26pt，不影响可达性
