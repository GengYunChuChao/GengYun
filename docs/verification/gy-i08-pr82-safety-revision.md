## 修订行为

- 生育期、地区为请求的必要条件时，缺失或不符均阻断适用资格，资料查阅与用量资格分别判断。
- 用量须绑定已核对的记录及来源、当前来源版本、具体登记记录、完整制剂字段和非空原文引用，并有数字、单位、原文条件；模拟、无效来源或不适用均拒绝。
- 制剂绑定采用两端相同的显式字段；既有 SHA-256 制剂身份函数不变。同一个有效合成 payload 在域库和小程序均可消费，避免按端重算不同身份键的夹具。
- 成分名称、名称与含量组合、单独含量采用精确匹配；多成分条件逐项匹配，局部名称或不同含量不会误命中。
- 详情页通过现有 profile-api 读取已确认作物及地区；空档案或读取失败仍可查到资料，但无用量资格。离页、重入、旧回调及身份变化不会恢复旧档案资格；消费档案时再次核对身份绑定。
- 两端规则版本为 `gy-i08/1.2.0`。未修改冻结 HTTP schema、数据库迁移、认证共享模块或生产资料。
