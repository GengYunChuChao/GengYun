## 6 风险与残留

1. **轮次读面不含作业状态**：`services/api/src/conversations/view.ts:87-95` 的 `TurnView` 七键没有 `job_state`/`error_code`，失败与超时在轮次读面都表现为 `answer: null`；要区分必须读 `GET /api/v1/jobs/{job_id}`。这是既有契约形状，本片**未改**（改会破坏接口形状）；若前端只看轮次列表，会把"失败"显示成"还没有回答"。
2. **上文有上限**：`CONTEXT_MAX_TURNS = 5`，更早轮次不进上文；标注文案如实写"最近 N 轮"，因此**不声称**覆盖全历史，也不编造轮次序号。
3. **节选仍是截断**：超过 `COMPOSER_EXCERPT_MAX = 400` 字的依据正文只带 400 字（已显式标注"原文更长"）；未标注的完整依据以资料页为准。
4. **资料正文里的用量陈述**：来源侧筛查只按 `dangerous_usage`/`prompt_injection` 规则命中剔除，**未命中规则但含用量措辞**的正文仍会随节选透出（属检索/资料基座范围，本片不改，已记为残留）。
5. 本片所有"通过"仅指**语义与失败可见性**在替身通路成立，不构成真实问答质量、准确率或整项 #12 验收。
