## 1 结论先行

1. **real 模式下三链各有两道闸，不是一道。** 提供者闸在前（503 `PROVIDER_UNAVAILABLE`），
   媒体闸紧随其后（409 `OBJECT_UNAVAILABLE`），TTS 还多一道内容闸（`checked_content`）。
2. **`#404`（W1）单独合入，三链只会从 503 走到 409，到不了 200。**
   `#404` 的 diff 只换「提供者怎么构造」——配置驱动三行（`services/api/src/app.ts:1060`、
   `services/api/src/routes/ocr.ts:195`、`services/api/src/routes/speech.ts:127`），
   **一个 media 端口文件都没碰**（`gh pr view 404 --json files` 实读：无 `ocr/media.ts`、
   `speech/media.ts`、`tts/media.ts`）。而三链的媒体端口都按 `executionMode` 各自选，
   real 一律选 `unwired`。⇒ **任何「合完 W1 就能 200」的口径都是假的。**
3. **装配层没有缺口，不需要为提供者新增注入项。** `services/api/src/routes/ocr.ts:189-190`
   的注释与 `:195-199` 的实现口径一致：服务缺省由本层按 `config.executionMode` 组装，
   产品装配 `app.ts` 只需一行调用；`deps.provider` 只是测试/装配方**可选**覆盖的旁路。
4. **TTS 是目前唯一「补齐前置即可到 200」的链**：提供者可由配置打开（`#404`）、
   媒体注入点**已在 main**（`app.ts:351` `synthesisMedia`）、内容闸依赖一行真实核对数据（§5）。

## 7 取证工具（`tools/verify-chain-e2e-r29.mjs`）

- **硬上限写死在脚本里**：`HARD_LIMITS = {tts:2, ocr:2, asr:2, total:6}`，预算 `QUOTED_CEILING_CNY = 2`；
  `resolveLimits()` **只允许收紧**，任何放大都抛 `LIMIT_WIDENING_FORBIDDEN`（有单测钉住）。
- 每次外呼前先打一行 `CALL <n> <kind>`；到上限即抛，失败只记失败码不重试。
- 单链运行：`--tts` / `--ocr` / `--asr`；结构化证据落 `<out-dir>/chain-e2e-r29-<phase>.json`
  （每条：`kind`/`http`/`durationMs`/`tokens`/`bytes`/`code`/`requestId`/`actualChargeCny`）。
- **逐次记账**：台账在 `reserve` 时取 `snapshotBefore`、`settle` 时取 `snapshotAfter`，
  由 `summarizeAccounting()` 对账；「台账记 1 次而计数器走了 2 次」会被判成
  `overage.exceeds=true` 并以非 0 退出（`OUTBOUND_BEYOND_LEDGER`），不许静默。
- **负控制**：不带 `--approve-real-chain` 的任何跑法都必须 `calls=0 / outboundSends=0`；
  `main()` 末尾断言 `outboundSends!==0 && !approveRealChain ⇒ NEGATIVE_CONTROL_BROKEN`。
- 凭据经 `tools/ai-config.mjs#loadPrivateEnvironment` 在进程内映射，日志只许出现
  `value_hits=<n>`（`countCredentialLeaks` 只返回值命中数，不打印值/长度/前缀）。
- **命中数由各臂自报（监工 1021-1806 [P2] 返修）**：plan-only 臂不接 `--private-env`、从不读凭据文件，
  所以在 `dryRun()` 里显式给 `value_hits: 0`；`liveRun()`（`--approve-real-chain`，`tools/verify-chain-e2e-r29.mjs:487`
  确实读所选凭据文件）给的是扫**本臂自己** say 行的真实命中数。`main()` 里改为「缺字段即
  `REFUSED VALUE_HITS_MISSING`」的 fail-closed，不再无条件清零——改前那一行会把任何非零检查结果
  改写成 `value_hits=0`。回归由 `tests/unit/chain-e2e-tool.test.mjs` 的合成哨兵用例钉住
  （合成值取自某条 say 行文案 ⇒ 必然命中 1 次；不使用真实凭据，证据文件里仍只出现计数）。
