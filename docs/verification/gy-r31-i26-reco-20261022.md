## 3 实现要点

入口：`services/api/src/recommendation/rank.ts:550` `rankRecommendations(input?)`。

- **输入只用仓库真实结构**：`packages/knowledge/herbicides/records-2026.json` 的 `records[]`、`packages/knowledge/catalog/crops.json` 的 `crops[]`、`packages/knowledge/catalog/species.json` 的 `species[]`。数据由调用方传入；模块**不读文件、不读环境变量、不发网络请求、不看当前时间**。
- **纯函数**：不修改入参，返回值与 `items`／`reasons` 全部 `Object.freeze`；排序不依赖对象键序、`localeCompare`、`Math.random`。
- **权重表**（`rank.ts:47` `RECOMMENDATION_WEIGHTS`，全整数，避免浮点累加使「分数=理由和」失真）：
  | factor | weight | 口径 |
  |---|---|---|
  | `crop_match` | +40 | 查询作物 ∈ 记录 `crop_ids` |
  | `symptom_match` | +30 | 症状按 `species.json` 别名归一后命中 `target_original`（按杂草种类计，至多 2 种） |
  | `keyword_match` | +10 | 关键词命中 药名/成分/使用场所/防治对象/剂型（至多 3 个） |
  | `unknown_symptom` | −15 | 症状不在别名表内：**降权不抛错**（至多 2 个） |
  | `source_validity` | +10 | `source.source_validity === 'valid'` |
  | `evidence_kind` | +6 / +3 / +1 | `research` / `mixed` / `experience`；枚举外一律 0（不猜） |
  | `review_status` | −5 | `unverified` 如实扣分 |
  | `unknown_crop` | 0 | 查询作物不在名录内：**不猜作物**，只留说明 |
  | `dosage_ignored` | 0 | 输入带剂量：丢弃、不回显数值 |
- **解释结构**：`reasons[]` 每条是 `{ factor, weight, detail }`，`weight` 是它对 `score` 的**全部**贡献；`score` 由 `reasons` 求和（`rank.ts` 内不存在第二条打分路径）。
- **确定性的细节**：`score` 降序 → `id` 升序（`a.id < b.id ? -1 : 1`，UTF-16 码元，跨机器一致）→ 输入次序；同分序列因此与 `records` 的传入顺序无关（测试用「反转输入」逐字节比对）。
- **越权输入**：`MAX_TEXT=200` 截断、剥控制字符/零宽/双向控制符（`\u0000-\u001F`、`\u200B-\u200F`、`\u202A-\u202E`、`\u2066-\u2069`）、`MAX_TERMS=8`、回显截断 `MAX_ECHO=24`，并记一条 `input_sanitized` 说明。
- **剂量安全**：只扫**浅层**键名（`dose|dosage|用量|剂量`），值整条丢弃、不参与打分、不回显；`dosage_form`（剂型）由 `rank.ts:202` 的 `NON_DOSE_KEYS` 排除——否则 20 条真实记录会全部误背一条 `dosage_ignored`。只扫浅层是有意的：`verification.not_collected` 里的「用药量（制剂量/亩）」是**缺项声明**，深层扫描会误判。
- **免责口径**：`rank.ts:40` `RECOMMENDATION_DISCLAIMER` 逐字沿用仓内既有「不能作为用药依据」（`miniprogram/pages/home/home.wxml:93`、`miniprogram/components/state-view/state-view.js:73`），并由 `packages/reference/risk-wording.mjs` 的 `assertRiskWordingSafe` 在测试里逐条校验。
- **不抛异常**：空输入、非对象、坏记录、未知作物/症状、重复 id 全部走「返回空列表 / `notes` 说明」分支；坏记录只记 `record_rejected`（含下标，至多 5 个）。
