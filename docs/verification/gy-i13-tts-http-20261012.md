## 2. 契约依据（`packages/contracts/openapi.json` 原文核对）

| 项 | 契约事实 | 本实现 |
| --- | --- | --- |
| 路径/方法 | `POST /speech/synthesis`（`operationId: createSynthesis`）→ `202 JobEnvelope` | 只注册 POST |
| 请求体 | `SynthesisInput{checked_content_ref:SynthesisTarget, locale:const "zh-CN"}`，`additionalProperties:false`，两字段必填 | Fastify `schema.body` 逐项复刻（闭集 `enum` + `const` + `min/maxLength` + `minimum`） |
| 安全 | `security: [{ userSession: [] }]` | `preHandler: guards.requireUser` |
| 参数 | `Idempotency-Key`（必填，8..128） | 路由校验 + 服务层二次校验（纵深防御） |
| `If-Match` | **本端点没有该参数**（`x-version-required: false`） | 不要求、不据此发 409/428；revision 绑定只在 body 的 `checked_content_ref.revision`（见 §6-C20） |
| 响应头 | `ETag`（资源 revision 强 ETag）、`Cache-Control`（私有/授权访问 no-store） | `ETag: "<job.revision>"`、`Cache-Control: no-store`（与 `profile`/`knowledge` 同口径） |
| 读面 | 该域**只有 POST**；读 JobState 的唯一接口是平台级 `GET /jobs/{id}`（`getJob`，`JobResult.oneOf` 含 `SynthesisResult`），属 GY-I01/#9 且**当前未装配** | **未自造** GET/DELETE；`GET`/`DELETE` 该路径实测 `404 NOT_FOUND`（§6-C01） |

**读面缺口（如实登记）**：本轮经 HTTP **无法**读取任务终态；`Synthesis` 只能经注入的 store 观察（§6-C22 显式标注）。

## 4. 集成脚本：装配与口径

- **测试内自建应用**：复用生产装配 `buildApp`（真实错误封套 / `notFoundHandler` / `removeAdditional:false` / 身份槽位），再注册本域插件；**未触碰 `app.ts`**。
- **合成身份**：
  - stub 应用 A：走**真实 stub 登录管道**（`POST /api/v1/auth/wechat` + `Idempotency-Key`）取得用户 A 令牌；用户 B 直接播种会话（`createUser`+`createSession`）。
  - real 应用 B：注入**替身微信提供者**避免任何外呼，播种会话。
- **真实回环**：`app.listen({host:'127.0.0.1', port:0})` + 真实 `fetch` 到 `http://127.0.0.1:<随机端口>`（非 `inject`）。
- **替身提供者/产物**：计数的替身提供者复刻真实适配器的**文本上限 fail-closed**；产物存储是**明确标注的替身**（内存只登记摘要，`substitute:true`、非 `audio/*`）。
- **零外发**：脚本不读凭据、不读 `.env`、不写盘；全部请求只到 `127.0.0.1`。
