## 11. 两处「契约字面 vs 加固」边界（保持原口径）

1. **101 码点文本**（C24）：契约**没有**文本长度上限，`maxTextCharacters=100` 是**提供者侧**口径。因此 HTTP **受理层不做判断**（仍 202），超限在**执行期**由真实适配器 fail-closed ⇒ 任务 `failed + INVALID_REQUEST`，**不静默截断**。这是**契约字面口径**，未在受理层加严。
2. **未声明的 `If-Match`**（C20）：契约 `x-version-required:false` 且**未声明该参数**，故本实现**忽略**该头并照常受理；revision 绑定只在 body 的 `checked_content_ref.revision`（C21）。若指挥/监工要求「带未知版本头即 400/428」属**加严**，需明确指示。
