# VID-DEMO：农药使用情景演示视频

状态：2026-10-10 用户确认的新增需求；尚未实现。采用模板素材合成，不强制接入付费视频模型。
本页是产品与实现需求增补，优先于旧需求中未包含视频的范围描述；原 F／AC 和 27 项任务不重编号。
“农药”在本演示可作为标签名称展示，不因此扩展真实用药资料库或允许给其他品类用量建议。

## 用户流程与内容

1. 扫描标签，由 OCR 给出名称；用户确认或校正后进入演示。
2. 选择近期、十年、二十年之一，制作并播放对应视频。
3. 视频在页面和画面中清楚显示“演示视频，非真实效果预测”。

时间段是创作情景标签，不是持续用药方案或预测结论。画面可虚构，无须保证真实农药效果。
模板可复用；合成需对应本次确认的名称与时间段，不把固定素材宣称为实时 AI 生成。
不生成处方、混配或剂量，不用演示结果替代实际登记资料。是否组合三段为一条视频 TODO。

## 实现边界与依赖

| 部分 | 要求 |
| --- | --- |
| 扫描入口 | 消费 OCR 原始／校正结果；名称不确定先确认，不静默认定药品 |
| 合成 | 合法来源模板＋药名／时间段／固定标识；素材缺失明确失败 |
| 播放 | 小程序可播放、重播；加载／生成失败可重试，离开可取消，不回写旧页面 |
| 权限 | 复用现有登录、媒体归属及用途守卫；默认不公开扫描图和视频 |
| 外发 | 模板可不发送原始标签；若新增第三方处理，先确定接收方、用途与留存，不能沿用 OCR 授权猜测 |
| 数据 | 输入名称与时间段、素材版本、生成状态和结果引用；具体字段／路由／状态契约 TODO，当前 OpenAPI 无视频接口 |
| 依赖 | GY-I10 OCR 完整入口；按实际保存方式复用 GY-I06／27。模板／播放器可用合成输入独立开发，完整功能须扫描接线 |

## 验收

- 扫描→名称确认→时间段选择→视频播放可完成；合成输入替身只证明局部组件。
- 三个时间段均有可播放结果，名称和选择一致，演示标识全程可见。
- 失败、取消、重复点击与离开返回不造成错视频或无限等待；有保存时校验归属及撤回／删除。
- 不要求真实性、科学预测准确率、长期田间样本或视频模型调用；原有 OCR 自身验收保持独立。
- 有完成入口、播放器与失败路径证据；不以只有静态截图代替“有可播放视频”。
