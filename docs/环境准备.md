# 环境准备

面向第一次拉取本仓库的成员，按顺序完成即可跑通工程。

## 前置检查清单

| 工具 | 是否必须 | 用途 |
| --- | --- | --- |
| Git | 必须 | 拉取代码、提交、推送 |
| 微信开发者工具（稳定版） | 必须 | 运行与调试小程序 |
| 小程序 AppID | 可选 | 正式 AppID 才能在公众平台授权插件；仅调试时可用测试号 |
| Node.js | 不需要 | 本项目无 npm 依赖与构建步骤 |
| GitHub 账号 | 必须 | 代码托管与协作 |

当前机器上 Git 与微信开发者工具已安装，可用如下命令自查：

```powershell
git --version
```

## 1. Git

若尚未安装，Windows 推荐使用 winget：

```powershell
winget install --id Git.Git -e --source winget
```

也可从 <https://git-scm.com/download/win> 下载安装包。**安装后需重开终端**再执行 `git --version` 验证。

身份配置说明：本仓库已配置**仓库级**身份（只影响本仓库，不污染全局）。新成员首次提交前需自行配置：

```powershell
git config --local user.name "你的名字"
git config --local user.email "你的邮箱"
```

## 2. 微信开发者工具

官方下载页：<https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html>
也可用 winget 安装：

```powershell
winget install --id Tencent.WeixinDevTools -e --source winget
```

首次启动需微信扫码登录。

## 3. 导入项目

1. 克隆仓库：

   ```bash
   git clone <仓库地址>
   cd challenge_cup
   ```

2. 微信开发者工具 → 「导入项目」
   - **目录**：仓库根目录（即包含 `project.config.json` 的目录）
   - **AppID**：测试号或自己的小程序 AppID
   - **后端服务**：选择「不使用云服务」
   - **开发模式**：选择「小程序」
     > 不要选择「多端应用」。本项目仅面向微信小程序，多端会额外生成配置文件并带来 API 兼容限制；将来若确需独立 App，再单独评估。
3. 点击「编译」，应看到「工程初始化完成」状态页

## 4. AppID 与插件

当前工程**未启用任何第三方插件**（语音方案待策划案确定，见 [`需求规划.md`](需求规划.md) 风险登记）。

个人 AppID 请勿写进仓库内的 `project.config.json`（多人协作会互相覆盖）。做法：

1. 复制 `project.private.config.json.example` 为 `project.private.config.json`
2. 填写自己的 AppID：

   ```json
   {
     "appid": "你的 AppID",
     "projectname": "challenge_cup"
   }
   ```

   该文件已被 `.gitignore` 忽略，不会提交。

后续若确定使用微信「同声传译」插件（TTS），需要：

1. 正式注册的小程序 AppID（**测试号不支持插件**）
2. 登录[微信公众平台](https://mp.weixin.qq.com/) → 「设置」→「第三方设置」→「插件管理」→ 添加「同声传译」（AppID：`wx069ba97219f66d99`）
3. 在 `miniprogram/app.json` 中声明插件后再使用

## 5. GitHub 协作配置

推荐使用 SSH（免重复输入密码）：

```bash
ssh-keygen -t ed25519 -C "你的邮箱"
```

将 `~/.ssh/id_ed25519.pub` 内容添加到 GitHub → Settings → SSH and GPG keys。

若网络限制 22 端口，可改用 443：

```bash
ssh -T -p 443 git@ssh.github.com
```

网络受限时也可使用 Personal Access Token（HTTPS 方式）。

## 6. 安全约定

- 本工程为纯小程序前端，**不需要 AppSecret**；AppSecret 只用于服务端调用微信接口
- 任何密钥、Token、`.env` 文件一律不得提交（`.gitignore` 已配置，但仍需自查）
- 截图中若包含 AppSecret，请及时在后台重置
- 日志中不要打印用户图片路径等敏感信息

## 7. 常见问题

**Q：`git` 命令找不到**
A：安装后需重开终端；确认安装时勾选了「Git from the command line」。

**Q：编译报 `app.json` 不存在**
A：检查导入的目录是否为**仓库根目录**（`miniprogram/` 的上一层），而不是 `miniprogram/` 本身。

**Q：同事拉取后 `project.config.json` 冲突**
A：说明有人把个人 AppID 写进了该文件。请把 AppID 移到 `project.private.config.json`，并把 `project.config.json` 还原为仓库版本。

**Q：为什么没有 Node.js 相关命令**
A：本项目不使用构建工具，属预期情况。

**Q：语音播报点不动 / 没有声音**
A：当前工程尚未实现该功能，属待开发项；此外测试号不支持插件，方案见需求文档风险登记。
