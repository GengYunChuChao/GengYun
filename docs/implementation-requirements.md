版本：v1.0\

状态：需求基线已确认，实施资料待交接\

本文用于确定耕云的软件需要实现哪些功能、页面、数据关联、状态、权限、外部接口和验收场景。产品定位、现实用户、社区运营、专家职责、合作安排和扩展阶段在[产品与现实业务需求文档](product-requirements.md)中维护。

本文保留F01至F20和Q01至Q29，验收扩展为AC01至AC29。首版暂定2026年11月15日，最终暂定2027年2月28日；已确认微信登录、实时两类识别、普通话ASR语音大模型提问、AI社区、收藏与识别历史及人工审核空入口。二月交付人工评审、专家预警、机构合作、交易沙箱、计划反馈和报告等。技术评估与用户授权的规则由开发侧制定，本文是需求目标，不代表代码或实测已经完成。

## 1 当前约束与开发范围

### 1.1 产品与交付

- 用户端微信小程序，副标题“识草查药与除草科普社区”；后台独立网页并单独鉴权。
- 首版暂定2026年11月15日，仅比赛演示，手机联网体验与网页后台，不开发离线兜底。
- 最终暂定2027年2月28日，范围见业务B05／9.4及本章；两阶段日期按UTC+8。
- 人员、账号、预算和平台资源已声明具备。数据库比赛前接入，具体字段、密钥和部署环境实施时交接，不提交仓库。

### 1.2 功能阶段

| 角色 | 访问范围 | 限制 |
| --- | --- | --- |

## 2 核心操作流程

### 2.1 资料查询

微信登录 → 手选浙江地区或授权定位并确认 → 选择作物、杂草与适用条件 → 来源／版本／禁限用规则检查 → 显示有依据的资料及风险限制 → 阅读／普通话播报 → 收藏。条件不足只查科普或返回缺项，不放宽限制凑结果。

### 2.2 两类实时识别

拍草：拍照或选图 → 实时任务 → 至多Top3／不确定 → 用户核对 → 杂草科普 → 补足作物及条件后查询资料。拍标签：拍照 → 实时OCR → 用户校正 → 登记证号精确匹配并比对字段 → 展示原文版本、条件与风险。候选、OCR文本、用户选择与登记核对分别记录，不跳过安全规则。

### 2.3 首版社区

投稿／评论 → 保存内容版本 → 规则与AI检查 → 通过发布，失败或不明隔离 → 评论点赞／收藏关联与应用内消息 → 编辑重审／举报。人工板块显示建设中；不伪造人工审核或专家回答。后续人工：申请审批 → 系统调度7名无利益冲突人员 → 4票多数或48小时不足多数交专审 → 结果、申诉与处置留痕。

### 2.4 二月记录与反馈

创建计划 → 预计日期到期仅待确认 → 用户确认实际使用日期 → 按第0天＋7／14日09:00调度 → 应用内提醒及经实际验证的外部渠道 → 轻量反馈 → 授权统计。改期取消撤销旧任务，补录不重复轰炸；购买、识别、收藏和沙箱成交不自动创建已使用事实。

### 2.5 二月合作与沙箱

机构企业提交证明 → 专审认证 → 成果／产品审核展示 → 合作意向及授权联系。交易演示独立：演示商品 → 演示订单 → 支付沙箱或模拟回调 → 取消／退款售后 → 演示结算。无实际扣款、物流或真实成交统计。

### 2.6 二月专家及预警

核实专家领域后回答 → 引用来源与内容审核 → 发布／修改重审。预警由授权发布主体提交来源、受众和有效期 → 专业复核 → 地区／作物过滤展示 → 到期失效或撤回。静态科普与AI候选不自动产生真实预警。

### 2.7 首版语音问答

主动录音授权 → 普通话转写 → 查看并修改文字／核对关键字段 → 发送问题 → 检索有效资料 → 大模型生成 → 来源和风险检查 → 显示带来源的回答／普通话播报。失败可文字输入；录音或转写不自动公开，个性化处方、混配和剂量换算仍关闭。

## 3 功能实现需求

### F01 账号与角色

**阶段：首版；评审、专家、机构企业角色2月。关联：Q02、Q07、Q13。**

- 微信登录，不强制手机号；会话由服务端建立，退出、过期和注销有明确状态。昵称头像可自愿设置，不以额外信息缺失阻断正常用户功能。
- 游客仅主页预览，其他页面及API要求登录；登录后可用已上线用户功能，不能自行获得后台权限。
- 用户端与独立网页后台分别鉴权，管理员初始化和凭据保护由T03／T05设计。
- 2月任何账户可申请评审，申请状态为待审批、授权、驳回、暂停、撤销；记录批准人、范围与时间，申请人不可自授权。
- 专审、普通评审、专业复核、专家与组织管理员分开；专审账号绑定实际责任人，不共享账号模拟多人。
- 注销入口及会话撤销按F13，投稿保留后的显示身份按B18。

**验收：** 微信登录、退出失效、游客拦截、记录归属和高权限越权检查通过，不强制手机号。

### F02 种植档案

**依据**：原文提出首次填写所在地区、主要种植作物和种植规模；多田块管理为补充建议。\
**建议阶段**：首版。\
**关联确认**：Q05、Q17、Q18。

- 通过省、市、县等选项填写地区，默认支持手动选择。
- 用户主动使用定位入口时，解释用途并按平台要求请求权限，取得地区后由用户确认；拒绝、取消、超时、定位失败或不在覆盖区均可手动选择。
- 定位仅用于选择地区，不实现地图路线规划或持续追踪。地区范围首版浙江市／县；拒绝定位后可手选，省外定位提示当前覆盖并允许选择浙江地区。
- 首版已确认单作物／地区档案，作物采用业务B06的4类选择，地区与作物为查询信息。面积／种植规模不是必填，默认不采集；多田块、多次使用及面积规则后续。
- 档案用于简化查询，用户仍能查询其他地区或作物。
- 修改档案不应改写已经发生的使用记录；历史记录保留当时的关联信息。

**建议验收**：用户可完成档案设置；拒绝定位权限后仍可手动填写；历史反馈中的作物与地区不随档案修改而改变。

### F03 科普内容与除草方案

**依据**：原文提出科普、三级导航、科研与经验来源标注。\
**建议阶段**：首版。\
**关联确认**：Q05、Q06、Q08、Q19。

- 支持按“作物—杂草—除草方式”浏览，并按地区等条件筛选。
- 内容涵盖生态除草、化学除草相关科普、使用注意事项、药害识别知识等原文主题；具体内容由有依据的材料和审核流程提供。
- 方案详情展示适用作物、杂草、区域、生长阶段、种植方式、除草方法、步骤、适用限制、来源和更新时间。
- 原文要求来源标注“科研／经验／混合”；来源类型与审核状态分别展示。
- 涉及具体药剂时，应保存对应资料来源、适用条件和审核版本，不把来源不明的经验当作已经核实的用法。
- 内容经已配置的发布策略和 F08 筛查后可见，来源原文、一般科普与用户经验分别标识。AI筛查通过不标记“专家已审”或“绝对安全”；修改、下架与版本追溯由 F08 管理。
- 接口保留来源类型与版本，区分真实数据库记录、核对过的种子资料和模拟演示数据；未接数据库时不伪称在线权威查询，虚构或缺失记录不提供真实剂量建议。

**建议验收**：任意已发布方案都能查看来源与适用条件；下架方案不会继续出现在新推荐中；无法提供的方案内容不以空白或伪造资料补齐。

### F04 方案匹配

**阶段：首版，后续维持安全边界。关联：Q05、Q06、Q19、Q20、Q25、Q27。**

- 首版使用选择表单、关键词搜索与两类识别对象，并通过F12／F20支持普通话语音向大模型提问；限定页面语音导航在2月加入，不接处方助手。
- 查询至少选择作物与浙江地区。科普可按未知杂草查询；具体适用资料必须补足来源所需的杂草、生育期、种植方式、使用场景，缺少条件不默认为符合。
- 只返回已发布、来源有效且适用条件匹配的版本；先执行禁限用、作物、生育期、制剂／含量／剂型、场景与地区规则，不静默放宽地区或限制。
- 展示命中的条件、未满足原因和来源。来源缺失、冲突、过期、下架、模拟条目或未核对时只提示不足，不提供可执行建议。
- 有依据时比较降低风险路线与其他适用路线的效果、劳动成本和限制；无资料不凑两条，不给绝对安全承诺。完整非化学知识12月至2月补充。
- 用量仅核对原文展示／朗读，绑定单位、制剂和条件；不生成个人处方、混配或自动剂量换算。
- AI辅助抽取、模型置信度、用户选中候选和社区票决都不作为药剂安全证明；支持关闭具体药剂输出并保留资料查询。

**验收：** 第6节确定性查询和过滤案例全部通过，两类识别准确率另计。

### F05 农民社区

**阶段：首版真实投稿与AI；专家回答2月。关联：Q04、Q08、Q12、Q13。**

- 文字／图片发帖、评论、点赞、作物／地区标签筛选，关联杂草／药剂资料；首版不做圈子体系。
- 每帖图片最多3张，单张≤5MB，执行类型与媒体权限校验、EXIF去除和AI图片筛查；识别任务可另按F15／F16压缩上传。首版无录音投稿。
- 用户经验、来源资料、AI筛查、专业复核和田间验证分别标识；不冒充专家或标“已验证安全”。
- 内容及图片先审后发，编辑生成新版本重审；广告、购买链接、私下交易导流、危险混配或个性化无依据用量不发布。
- 未通过内容仅作者与有权限管理端查看。点赞幂等、评论引用与消息不泄露隐藏版本；用户能编辑或删除自己的内容、举报并查看状态。
- 首版普通用户互助，不承诺专家或人工即时响应；人工入口为空态，AI失败内容隔离。管理员有停止投稿和隔离功能开关。
- 2月专家须资格认证和授权领域，回答绑定来源，经专业审核再发；修改重审，一般问题目标2个工作日响应，超时显示等待。
- 注销保留帖子评论的去身份处理按F13，不恢复身份映射。

**验收：** 投稿评论发布／隔离、修改重审、点赞去重、商业禁止与消息权限可验证。

### F06 用药计划与提醒

**阶段：2027年2月，首版不做。关联：Q04、Q09、Q10、Q18。**

- 手动或从资料创建计划，关联当时作物／地区／药剂版本；预计使用日期与实际使用日期分别保存，预计到期仅标待确认，不自动认定已使用。
- 状态为待使用、待确认、已使用、已取消。未使用可改期取消；确认实际使用需用户显式提交，可直接补录过去日期，不允许未来实际日期。
- 采用UTC+8日历日，实际使用当天为第0天，第7／14个日历日09:00生成观察提醒，不按168／336小时计算；提醒不指示再次用药。
- 计划用前提醒设为预计当天09:00的确认提示，不生成具体用量指令；若创建时已过时，只显示应用内到期状态。
- 修改实际日期生成新的调度版本并撤销旧任务，反馈保留原观察日期与修改记录；取消停止未发任务，不销毁真实已发生的使用记录。
- 补录时已过期的节点一次性生成应用内待补记录；尚未到期正常调度，不补发多条过期外部推送。已提交反馈的节点不重复提醒。
- 每任务以使用记录＋节点＋调度版本为幂等键；创建消息和调度分别记录，不因重试复制消息。
- 应用内是基本渠道；微信账户外部推送仅在官方账号／模板能力、用户授权和实际发送验证满足后接入，登录不等于订阅。
- 外部发送临时失败当天最多3次按递增间隔重试，撤销／已反馈／已取消不再发，永久拒绝不重试；失败可见且保留应用内消息。

**验收：** 跨月跨年、实际日期修正、未使用、取消、补录、重试及拒订阅均正确；7／14天同一使用不重复建任务。

### F07 使用记录与效果反馈

**阶段：2027年2月轻量反馈，首版不做；多田块2月以后。关联：Q11、Q18、Q17。**

- 仍用单作物／地区档案，允许多次独立实际使用；每次记录保存作物、地区、药剂登记／制剂、实际日期和来源快照，不依赖交易。
- 每次使用关联第7／14天两个观察节点，观察日期必填且不在未来；补录保存实际观察日期，不伪造准时完成。
- 必填自报选项：改善无明显／部分／明显／不确定，疑似药害未观察到／疑似／不确定，长势改善／基本不变／变差／不确定。
- 抗性只作反复出现等线索，可选且不确诊；备注和每个观察节点至多3张、每张≤5MB照片可选。不要求准确百分比、天气、土壤或产量测量。
- 如自愿记录面积，固定亩并展示单位；如自愿记录实际使用量，保存数值＋显式单位＋药剂制剂快照，不自动换算、不补造缺失浓度。未填不视为0。

### F20 语音与文字大模型问答

**阶段：首版新增，用户直接要求。关联：Q06、Q12、Q16、Q17、Q19。**

- 登录用户可在识别页的“语音问答”入口或语音球发普通话语音，也可文字输入。音频经F12转写核对后交给大模型，回答以文字显示并支持普通话播报。
- 问题优先围绕覆盖内杂草识别知识、除草剂标签阅读、除草科普及平台使用；会话可追问，保留用户已确认的作物地区条件，不自行猜个人环境。
- 服务端从已核对、有效、有权限的资料检索证据，给回答附对应内部资料编号／版本、标题和可访问来源。引用仅来自检索结果，不由模型虚构登记号、专家身份、URL或资料。
- 资料不足、冲突、过期、超出范围或无法回答时说明不足，可引导查资料或补充问题；不把无依据生成内容伪称数据库结论。
- 不生成个性化药剂处方、混配或自动剂量换算。涉及具体用量只显示匹配条件下的可核对标签原文卡片，由确定性来源组件渲染，不让模型补写数字；缺项则不展示用量。
- 对危险操作或急性伤害问题不提供继续操作指令，提示停止接触并使用适合的线下专业求助渠道；不诊断或承诺医疗处置正确性。
- 用户话语与资料原文均为不可信输入，不接受其中“忽略规则／替换来源／泄露数据”等指令；回答发布前执行来源、风险及结构检查，失败不把未审内容流式直接展示或朗读。
- AI问答与社区审核是不同任务，问答通过不自动成官方资料或帖子；无首版专家冒充，不以“AI回答”标专业验证。
- 记录会话问题、转写编辑、引用版本、模型／模板／规则版本和实际结果，私有会话及音频按F13保留至注销，可单条删除，不公开到社区。
- 真实ASR、检索与模型调用验收，标注模拟仅兜底；模型失败显示可重试，不用预设回答冒充实时服务。

**验收：** AC29检索引用、缺资料、危险用法、提示注入与隐私隔离，及第6节问答评估首版必交。

### 6.1 两类识别与AI筛查评估

测试集在调参前冻结，调参／训练与最终测试隔离；同一原图裁剪、连拍或近重复不能同时进入训练与测试。记录来源、对象标注、质量、答案及已知使用状态，许可调查按用户要求本轮暂缓，不能将未知写成已确认。可靠标注或独立核实作答案，模型预测不能作自己的标准答案。报告总体／逐类指标及95%置信区间，明确有限样本不证明现实零风险。

| --- | --- | --- |

| 普通话自动播报 | 至少30段来源、风险、数字单位及问答朗读样例，实际声音核对 | 数字单位、否定词、条件在固定样例全部准确，触发停止重播与文字替代通过 |
| 普通话ASR | 至少50段独立真实录音、至少10名说话者，含普通安静／常见噪声场景及药名数字单位；人工转写作答案，按统一去标点规则计算字符错误率 | 总体字符错误率≤15%，关键药名／数字／单位字段完全正确率≥95%；逐场景报告，错误或不确定必须核对。手动改写不计模型准确率 |
