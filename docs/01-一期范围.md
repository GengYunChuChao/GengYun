# 01 · 一期范围（3 人 × 赛期可行）

> 上游依据：[00-开发思路图.md](00-开发思路图.md)（**长期愿景，非本期施工图**）
> 本文档只定义**一期做什么、不做什么**，是本期开发的唯一依据。
> 版本 v1.0 ｜ 2026-10-02

---

## 一、为什么需要这份文档

`00-开发思路图.md` 描述的是**完整产品**：5 个 Tab、6 个中台、7 个数据库、管理后台，团队配置 8-9 人、周期 10-14 周。

而实际团队是 **3 名本科生**（尹一、刘轩、陈贤豪）+ 2 位兼职指导教师，赛期有限。

若直接按思路图施工，常见结果是：数据没建完、识别缺训练数据、后台没做完，每一块都是半成品，答辩时拿不出一个能跑通的闭环。

因此一期只取思路图中**不依赖 AI、不依赖后端团队、可独立交付**的部分，做成一个**真正跑得通**的最小闭环。

---

## 二、一期目标（一句话）

> 农民设好「我的地区 + 我的作物」，就能查到**有来源可追溯的除草剂信息与用药方案**，并且能**听**到内容；高危农药有强制提醒。

---

## 三、一期做什么

| 模块 | 范围 | 验收标准 |
| --- | --- | --- |
| 数据底座（文本） | 除草剂库、杂草库、作物库、地区—杂草关联 | 数据以 JSON 内置在小程序内；每条标注来源；一期限定 1 个地区 |
| 农药查询 | 分类列表（生态 / 低危 / 高危）+ 关键词搜索 + 详情页 | 详情含：登记证号、有效成分、剂型、适用作物、防治对象、用量、安全间隔期、注意事项 |
| 杂草查询 | 列表（按作物 / 地区筛选）+ 详情页 | 详情含：形态特征（配图）、发生规律、防治要点 |
| 方案推荐（规则） | 地区 + 作物 + 生育期 + 目标杂草 → 输出方案 | **规则匹配，非 AI**；结果标注来源，生态优先排序 |
| 高危强提醒 | 高危农药详情页红字 + 语音播报 + 震动 | 文本与语音提醒不可关闭；高危判定须引用权威名录 |
| 语音朗读 | 详情页 / 方案页「朗读本页」 | 见第四节「语音方案待决」 |
| 个人中心 | 我的地区、我的作物、收藏、浏览历史 | 全部本地存储，一期不做登录 |

---

## 四、语音方案待决（一期最大的不确定项）

已实测：**小程序测试号不支持第三方插件**，微信「同声传译」TTS 在当前 AppID 上无法使用。三个可选方案：

1. 拿到正式 AppID 后授权插件（成本最低，需等注册主体确定）
2. 后端 TTS 合成音频（效果可控，但一期不引入后端）
3. 关键内容预置录音（完全离线，覆盖面有限）

**一期建议**：所有文案按「可朗读」规范编写（短句、口语化、无生僻符号），语音能力先留接口；拿到正式 AppID 后接入方案 1。**不要把语音做成阻塞项。**

---

## 五、一期明确不做（后置到二期 / 三期）

| 不做 | 原因 |
| --- | --- |
| 拍杂草识别（AI） | 无图像数据集；杂草幼苗期形态近似、田间混生，识别难度高于病害 |
| 拍农药标签 OCR + 登记证号匹配 | 瓶身反光弯曲影响准确率；农药登记数据无公开 API |
| 社区（发帖、评论、点赞、审核） | 工作量 + 内容审核责任，3 人无法维持 |
| 地区智能推送、消息中心 | 依赖运营与推送配置 |
| 语音助手 / 方言包 / 语音命令 | 依赖 ASR 与方言模型训练 |
| 管理后台 | 一期用 JSON 文件 + Git 管理数据，无需后台 |
| 在线售药、专利对接 | 存在硬性合规障碍（农药经营许可） |
| 区域效果报告（申报书原创新点之一） | 需要真实用户规模与数据积累，一期无法验证 |

## 六、与申报书的差异（必须由策划同学修订申报书）

一期与已提交的申报书存在方向差异，**必须同步修订，否则答辩时作品与申报材料不符**。

| 申报书原文内容 | 一期实际情况 | 建议处理 |
| --- | --- | --- |
| 创新点：使用反馈闭环、区域效果报告 | 一期不做 | 改为"二期 / 三期规划"，或替换为"地区—作物—杂草—方案关联推荐" |
| 技术关键 2：用户反馈结构化采集 | 一期不做 | 从"技术关键"降为"后续规划" |
| 技术关键 3：除草剂效果评估模型 | 一期不做 | 同上 |
| 主要指标：注册用户 ≥ 5000、日均发帖 ≥ 200 | 一期无法验证 | 改为可验证指标（如覆盖 X 种作物、Y 套方案，经 Z 位农技人员审核） |
| 专利对接、农资交易 | 一期不做 | 从一期范围移除 |
| 参考文献含知乎问答、"未见报道"断言 | 与实现无关 | 见 [评审问题与风险清单.md](评审问题与风险清单.md) 第四节 |

> **修订口径建议**：一期做「权威数据 + 规则推荐 + 语音可达」，二期做「识别」，三期做「反馈闭环与效果报告」。每一期都有可交付成果，申报书按分期表述即可保持真实。

## 八、前置条件（不满足则不宜开工）

1. **数据来源确认**：农药与杂草信息取自哪些权威来源？谁录入、谁审核？（决定作品"科学性"）
2. **地区范围确认**：一期只做哪个区域（建议限定 1 个省市，做深做透）
3. **语音方案决策**：见第四节
4. **申报书修订**：见第六节
5. **合规确认**：免责声明措辞、高危名录来源、用户隐私保护指引
