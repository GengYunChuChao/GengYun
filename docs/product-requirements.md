## 1 产品定位与目标

### B01 产品定位

**Q01已确认。**

产品名称“耕云”，对外副标题“识草查药与除草科普社区”。首版面向比赛演示，以识草、核对除草剂标签、查阅科普和农民交流为主；后续加入使用记录、观察提醒、人工治理、专家及机构合作。识别结果是候选查询对象，不是鉴定证明或个人用药处方。

### B02 产品目标

**依据：原文提出。**

1. 帮助农民找到符合地区、作物、杂草和生长阶段的除草知识，理解方案的适用条件。
2. 帮助用户安排使用计划、记录真实使用情况，并持续观察效果。
3. 让农民经验与科研资料能够交流、讨论和核实，内容来源可以辨认。
4. 为科研机构与企业提供成果对接与田间效果信息。
5. 通过语音、大字号和图片引导降低使用门槛。

以上是完整产品目标。Q04 已确定首版先做识别、科普和社区；目标2中的计划与效果记录后置，科研、企业对接和区域报告继续保留后续规划。

杂草照片识别和药剂标签 OCR 均已确认为首版需求。地区、作物仍作为科普筛选条件；地区预警和专家回答不进入首版交付。

Q05已明确浙江地区，并授权开发侧补充常见作物、杂草和药剂范围。用户列举的稗草、狗尾草和荨麻属于杂草／植物识别对象，不作为种植作物。开发侧确定下列初始范围，不再要求用户逐个选择。

| 类别 | 首版规划范围 | 说明 |
| --- | --- | --- |
| 地区 | 浙江省，地区选择到市／县 | 全省可选不表示每个县都有独立验证资料；按资料覆盖显示 |
| 种植作物 | 水稻、玉米、大豆、油菜，共4类 | 水稻作为主要演示档案，其余支持切换；每个用户保留一个当前作物／地区档案 |
| 杂草／识别对象 | 稗草、狗尾草、荨麻类、马唐、牛筋草、看麦娘、藜、空心莲子草，共8组 | 作为科普与模型评估目标；荨麻类等俗名须在资料导入时对应规范对象编号，不能把一个名称混为任意近似物种 |
| 药剂资料 | 目标20条除草剂登记／标签记录 | 优先选择浙江相关作物／场景、有可核对标签及有效登记的普通除草剂；不纳入其他农药品类或限制使用产品作为可选方案，不按商品销量选药 |

作物范围参考[浙江省农业农村厅粮油生产文件](https://nynct.zj.gov.cn/art/2024/5/11/art_1229142036_2519496.html)，作为演示范围选择依据；实际药剂字段与标签可参考[农业农村部农药检定所登记资料查询页](https://www.icama.cn/BasicdataSystem/pesticideRegistration/viewpd.do)。具体内容核对与识别标注在实施阶段完成。原申报书20作物、50杂草、100方案属于后续目标。

## 4 科普内容与可信度设计

### B08 内容范围与准备

**Q19已确认数据库在比赛前接入，许可调查本轮暂缓。**

用户负责提供数据库接入，开发侧提供可替换的资料适配层；首批覆盖按B06执行。未接入时允许有来源的种子资料或明显标注的模拟资料，来源类型、核对状态、版本、更新时间和实际数量必须保留。模拟记录不提供真实药剂用量依据，不虚构登记、专业审批或覆盖完成情况。

科普涵盖识别特征、除草剂资料阅读、安全注意与普通除草知识。12月至2月补充轮作、覆盖、人工／机械除草等非化学知识，由专业人员审查适用条件。许可状态只记录已知事实，不将本轮暂缓理解为资料已获许可。

用户最新追加首版普通话语音识别，用于发语音向大模型提问。首版提供主动录音、转写核对、资料检索问答和回答播报，亦可文字输入；不要求语音导航。回答说明依据与不足，不替代专家，不生成个性化处方、混配或剂量换算。私有音频、转写和会话按B18保存删除，录音不自动公开或供第三方训练。

### B09 审核责任与认可标签

**首版发帖、评论开放，沿用此前“先AI审核”的已确认方向；仅人工审核板块首版留空。人工评审2027年2月上线。**

首版帖子、评论与图片经过规则和AI筛查，状态分为待筛查、筛查通过、待复核、驳回、已发布、已下架。筛查通过与发布分开；来源冲突、危险用法、广告、交易导流、服务失败或无法判断时不公开。内容编辑重新审核新版本，原审核结果不能套用。人工入口首版显示建设中，不伪造审核任务、审核人或结论；待复核内容不因缺少人员自动放行。

AI筛查、社区票决、专业资料复核与田间验证分别标记。公众票决只决定社区可见性，不授予专家资格，不审批药剂规则，不把社区经验自动转为官方用法。

**人工评审的已确认规则与实施补全：**

| 项目 | 规则 |
| --- | --- |
| 申请与授权 | 任何账户均可申请；专门审核人员审批、暂停或撤销权限。申请不自动赋权，普通评审和专业复核分开 |
| 分配 | 系统调度，每案7名不同且有权限的评审员；排除作者、举报人及可识别的利益关联方，利益冲突时回避并替换 |
| 评审界面 | 展示脱敏的争议原文版本、举报理由、证据来源及规则；禁止复制传播无关个人信息 |
| 投票 | 每人每案一票，仅保留／下架两个有效选项，至少4票同意同一结论即形成不可被剩余票数改变的多数 |
| 截止 | 从首次分配起48小时，替换评审员不延长原截止；已取得4票可提前结案 |
| 票数异常 | 7个有效二元票不会平票；缺席、回避或无效票导致截止时均不足4票，记为未达多数并交专门审核人员处理，不宣称票决完成 |
| 申诉 | 作者可从结果页提交证据，7日内最多一次常规申诉；系统通知，交未参与原案的专门审核人员复核，3个工作日内给结果或延期原因 |
| 恶意投票 | 有证据的串通、刷票、多账号操控或骚扰，由专门人员复核后封禁账号并撤销评审权限；单次判断错误或投少数票不属于恶意 |
| 留痕与安全 | 保存内容版本、分配、票、原因、处理者与申诉；危险内容先隔离，不能被多数票绕过禁限用或来源冲突规则 |

审批、撤销、紧急处置和申诉由专门审核人员处理；农技资料需要相应专业资质，不因社区审核身份自动获得。谁都可以申请这一条件已确认，身份核验与系统风控属于实现任务，不再增加业务资格门槛。

## 5 社会交际与社区设计

### B10 社区的作用

首版提供普通农民的问答互助、经验分享、文字／图片发帖、评论与点赞；按作物／地区标签浏览，可关联杂草或药剂资料。首版不提供专家回答。用户经验不是已验证结论，拍照与收藏也不是实际用药事实。

### B11 社区运营规则

首版真实发帖、评论及AI筛查上线，人工审核入口留空至2027年2月。内容没有通过检查前不可公开；无人工复核时待复核状态保留，不承诺即时处理。允许举报和查看处理状态，初期依规则隔离，2月接入专门审核队列和申诉。

首版禁止社区广告、购买链接和私下交易信息；该限制在社区继续执行，后续认证企业的官方资料入口与社区分开。不得发布无依据的剂量、混配、危险操作、私人联系方式导流或冒充专家内容。用户可修改、删除自己的内容；修改需要重审，下架保留必要证据而非直接销毁。

管理员可维护分类、内容来源和功能开关；“人工审核板块为空”不取消基础账号管理或停止投稿的控制能力。帖子数、点赞和多数票不作为科学有效或安全证明。

## 6 使用行为与真实效果评价

### B12 提醒与回访的现实目的

| 对象 | 处理规则 |
| --- | --- |
| 对外推理 | 优先接入可限制留存、禁止擅自训练并支持删除确认的服务；外发前最小化数据，记录接收方、目的、对象和实际授权 |

### B19 药剂范围与内容安全

**Q25／Q27已确认降低风险表述、来源查询与用药功能边界；首版药剂只覆盖除草剂，具体资料范围由开发侧决定。**

图中要求初期只覆盖除草剂，建立权威、可审核、可追溯的药剂资料，按登记证号核对标签，并设置禁用／限用过滤。需要明确数据提供方、覆盖地区、更新时间、审核责任与规则有效期；将图中“合规红线”作为内容准备要求，不直接视为已经完成法规核查。

“只做除草剂”作为首版药剂品类边界，后续可增加其他品类。普通除草安全知识保留；轮作、覆盖等完整非化学方案库不列为首版必交，可作为后续扩展。田埂／田间等场景与省市县地区分别建模。

用户要求避免人受伤，并希望提供“有风险”和“绝对安全”的两类选择，允许低风险路线除草效率较低。此处记录为安全与选择目标，不承诺现实中零伤害。误识别、现场条件、防护行为、工具操作和资料变化均可能产生风险，AI 与投票不能作出绝对安全保证。

**本轮已确认的可执行边界：**

- 界面采用“优先降低风险的路线”和“其他适用路线及风险说明”，明确对人员、作物、动物和环境的条件；即使非化学方法也列出操作风险，不展示“绝对安全”“零药害”“AI已保证安全”。
- 先执行适用与禁限用检查，再比较效果、成本、劳动投入和风险。禁用、不适用、资料缺失、制剂冲突、有效期不明的对象不能作为可选方案；不能为了凑足两个选项提供危险内容。效率和作物影响只展示有来源的结论，不由 AI 猜测。
- 首版 AI 审核用于内容筛查和原文比对；没有专业复核支持时，药剂功能以权威登记／核准标签原文查询与风险提示为基线，不提供 AI 生成的个性化用药处方、混配或自动剂量换算。是否扩展需另行确认和验证。
- 来源、使用范围、方法、剂量、制剂条件、注意事项和防护要求必须一起展示，不能只朗读数字。实际条件不明、用户不能确认杂草或标签有冲突时停止具体用药推荐，提供继续查询与线下农技指导入口。
- 已发布的危险内容可隔离，下架后同步使搜索、推荐、收藏跳转和消息失效；保留版本与依据。首版不实现人工处置业务时，不能依赖尚未配置的审核人完成放行；危险或不明内容保持不可见。

上述边界已由用户确认。作为资料核对依据，[农业农村部公开的《农药管理条例》第三十三至三十五条](https://fgs.moa.gov.cn/flfg/202312/t20231205_6442161.htm)涉及用药防护、遵循标签范围／方法／剂量及环境保护要求；具体药剂仍须核对届时有效的标签和限制规则。
