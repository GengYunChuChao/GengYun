## 3 使用边界

**图片不入库、仅本机演示。** 四张图只存在于上面那个本机目录，不随仓库分发，不打进安装包，也不出现在任何提交里；仓库内只保留本页这份「来源与许可」的文字记录。

**再分发须遵守各自许可证。** 三张 CC BY-SA 3.0 的图（01 / 02 / 04）如果被转贴、剪辑、拼版或放进对外材料，必须署名（作者 + 许可证名 + 指向 Commons 页面或原许可文本的链接），并且以**相同协议**（CC BY-SA 3.0 或兼容的 BY-SA 版本）发布；署名的位置要让人能把图与作者对上。03 属公有领域，无署名义务，但本页仍保留出处，方便回溯。

**许可可能被上传者更新。** 上面记的是本机 `credits.json` 抓取时的读数；对外使用前请打开对应 Commons 页面，以其当时标注的许可为准。若发现许可已变（例如被改判为「非自由」），这张图就不该再用于演示。

**不作为物种鉴定依据。** 这些图是「演示素材」，不是标本照；文件名里的学名只说明它拍的是什么，不构成鉴定结论（同页的证据边界见 [GY-R92 证据页](../verification/gy-r92-demo-photo-identify-20261109.md)）。
