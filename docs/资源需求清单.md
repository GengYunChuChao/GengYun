## 四、数据格式与素材规范

整理资料前请先看这一节，按下面的字段填写，可以省掉大量来回确认。

### 4.1 农药信息格式（一行一种农药）

| 字段 | 说明 | 填写例子 | 是否必填 |
| --- | --- | --- | --- |
| 农药名称 | 包装上的商品名 | 金大地 | 必填 |
| 有效成分与含量 | 包装上的成分和百分比 | 苄嘧磺隆 30% | 必填 |
| 剂型 | 包装标注的剂型 | 可湿性粉剂 | 必填 |
| 登记证号 | 包装上的批准号 | PD20200345 | 必填 |
| 防治对象 | 能防哪些害 | 稗草、千金子 | 必填 |
| 适用作物 | 用于哪种作物 | 水稻 | 必填 |
| 每亩用量 | 包装上写的用量 | 30 克 | 必填 |
| 稀释倍数 | 需要兑水稀释时填 | 稀释 300 倍 | 选填 |
| 安全间隔期 | 打完几天后才能收获 | 15 天 | 选填 |
| 注意事项 | 包装上的禁忌和警示 | 不可与其他除草剂混用 | 必填 |
| 资料来源 | 从哪查到的 | 中国农药信息网 | 必填 |

**特别重要**：登记证号和资料来源**不能编造**。这两项是评委核对真伪的依据。

### 4.2 杂草信息格式（一行一种杂草）

| 字段 | 说明 | 填写例子 | 是否必填 |
| --- | --- | --- | --- |
| 杂草名称 | 含常见别名 | 稗草（别名：稻稗） | 必填 |
| 危害作物 | 主要危害哪些作物 | 水稻、玉米 | 必填 |
| 形态特征 | 怎么认出来 | 茎细长、叶片狭长向外斜伸 | 必填 |
| 发生规律 | 什么时间容易长 | 稻田 5 至 8 月最常见 | 选填 |
| 防治要点 | 怎么防 | 插秧后 7 天内早期施药 | 选填 |
| 资料来源 | 从哪查到的 | 农技手册 | 必填 |

### 4.3 用户反馈数据格式（小程序里让农民填的）

| 字段 | 填写形式 | 说明 |
| --- | --- | --- |
| 用药后第几天 | 自动计算 | 记录用药日期后，第 7 天和第 14 天提醒填写 |
| 除草效果 | 滑动选择 0 至 100 | 杂草减少了多少 |
| 药害情况 | 单选：无 / 轻 / 中 / 重 | 作物有没有受到影响 |
| 作物长势 | 单选：良好 / 正常 / 偏弱 | 施药后的长势 |
| 抗性迹象 | 单选：有 / 无 | 同一片地反复打同一种药还有效吗 |
| 现场照片 | 拍照上传 | 杂草和作物现状 |
| 补充说明 | 语音或文字 | 农户自己的说法 |

> 整理数据时请保证能对应上以上几项，方便后续统计。

**Q：这些都必须提供吗？**

A：这是涉农用药建议，信息错误可能造成药害。评委看重"药说得准不准"，且必须可追溯。

**Q：我的账号信息安全吗？**
A：只使用子账号和只读权限，不会改动主账号设置。密钥由团队统一保管，不在群里传递。
