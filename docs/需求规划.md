# 需求规划

本文档记录 **以作品申报书为准** 的功能范围、技术约定与待确认事项，策划案定稿后须在此同步。

> 申报书的完整分析与风险清单见 [评审问题与风险清单.md](评审问题与风险清单.md)（含 12 条待澄清问题与形式审查问题）。

## 一、功能方向

### 1.1 主线（2026-09-30 确认）

小程序主线 = **除草科普内容 + 农民使用反馈采集**，与《浙江农林大学第二十届"东湖杯"大学生课外学术科技作品竞赛作品申报书》一致。

| 模块 | 说明 |
| --- | --- |
| 科普内容浏览 | 按"作物—杂草—除草方式"三级检索；每条方案标注来源（科研 / 农民经验 / 混合） |
| 语音播报 | 朗读**科普内容与表单**（适老化，解决部分农民不识字的问题） |
| 用药提醒 | 记录用药计划，使用后第 7 天、第 14 天提醒填写反馈 |
| 反馈采集 | 表单 + 选项引导 + 图片上传 + 语音输入；覆盖除草率、药害情况、作物长势、抗性迹象 |
| 简易统计 | 个人历史记录与汇总（区域效果报告明确不做） |

### 1.2 明确不做 / 后置（赛期内）

- **拍照识别病害/农药、识别结果的语音播报**：这两项为教师在研讨会上提出的**后续扩展方向**，本阶段先落实申报书主线，待主线完成后再评估是否纳入（会拉低"先进性"论证，且申报书正文无对应技术描述）
- 社交板块（发帖、评论、点赞）：工作量与内容审核风险高
- 农资电商交易、专利对接：涉及农药经营许可等硬性合规障碍
- 区域效果报告与对外数据服务：数据量与法律风险

> 详细理由见 [评审问题与风险清单.md](评审问题与风险清单.md) 第 7.2、7.3 节。

## 四、数据结构约定（草案，待策划确认后固定）

### 4.1 科普条目

```js
{
  id: 'rice-weed-echinochloa',
  crop: '水稻',              // 作物
  weed: '稗草',              // 杂草
  region: '长江中下游',       // 适用区域
  method: '一封一杀',         // 除草方式
  source: 'research',        // research 科研 | experience 农民经验 | mixed 混合
  sourceDetail: '全国农技中心 2024 年方案',  // 来源说明，须可追溯
  steps: ['…'],              // 操作步骤
  cautions: ['…'],           // 安全注意事项
  updatedAt: 1730000000000
}
```

### 4.2 反馈记录

```js
{
  id: '…',
  planId: '…',               // 关联的用药计划
  crop: '水稻',              // 作物类型
  herbicide: '…',            // 使用的除草剂名称与剂型
  location: {                // 位置按最小必要原则采集，展示时脱敏
    province: '', city: '', county: ''
  },
  indicators: {
    weedControlRate: 85,     // 除草率（%）
    cropInjury: 'none',      // 药害等级：none | mild | moderate | severe
    cropGrowth: 'normal',    // 作物长势
    resistanceSign: false    // 是否出现抗性迹象
  },
  images: [],
  voiceText: '',             // 语音输入转写文本（口语化，需结构化处理）
  createdAt: 1730000000000
}
```

约定要点：

- 所有剂量与药剂品种类信息必须可追溯到来源，前端不得硬编码未经审核的内容
- 位置信息按最小必要原则采集，对外展示需脱敏
- 字段名一旦确定不要随意改名，避免前后端解析失败
