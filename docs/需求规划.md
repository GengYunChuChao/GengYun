## 一、本期方向（2026-10-02 确认）

一期 = **权威除草剂数据 + 规则推荐 + 语音可达**，目标是做出一个能跑通、能演示的**最小闭环**。

| 模块 | 说明 |
| --- | --- |
| 数据底座 | 除草剂库、杂草库、作物库、地区—杂草关联（JSON 内置，条目必须标注来源） |
| 农药查询 | 分类列表（生态 / 低危 / 高危）+ 搜索 + 详情（登记证号、有效成分、适用作物、用量、安全间隔期、注意事项） |
| 杂草查询 | 列表（按作物 / 地区筛选）+ 详情（形态特征、发生规律、防治要点） |
| 方案推荐 | 地区 + 作物 + 生育期 + 杂草 → **规则匹配**输出方案（非 AI），生态优先排序 |
| 高危强提醒 | 红字 + 语音 + 震动，文本与语音提醒不可关闭 |
| 语音朗读 | 详情页 / 方案页朗读；具体方案待定（见一期范围第四节） |
| 个人中心 | 我的地区、我的作物、收藏、浏览历史（本地存储，本期不做登录） |

**本期不做**：AI 识别、农药标签 OCR、社区、地区推送、语音助手 / 方言包、管理后台、在线售药、区域效果报告。
完整清单与原因见 [01-一期范围.md](01-一期范围.md) 第五节。

## 三、数据结构约定（草案，确认后固定）

### 3.1 除草剂

```js
{
  id: '...',
  name: '...',             // 商品名或通用名
  registrationNo: '...',   // 农药登记证号（用于溯源）
  ingredient: '...',       // 有效成分及含量
  formulation: '...',      // 剂型
  hazardLevel: 'low',      // eco 生态 | low 低危 | high 高危
  targets: ['...'],        // 防治对象（杂草）
  crops: ['...'],          // 适用作物
  dosage: '...',           // 用量（必须标注来源）
  dilution: '...',         // 稀释倍数（如适用）
  safetyInterval: '...',   // 安全间隔期
  cautions: ['...'],       // 注意事项与禁忌
  source: '...',           // 来源说明，须可追溯
  updatedAt: 0
}
```

### 3.2 杂草

```js
{
  id: '...',
  name: '...',             // 杂草名称（含别名）
  crops: ['...'],          // 主要危害作物
  regions: ['...'],        // 主要发生区域
  features: '...',         // 形态特征
  habit: '...',            // 发生规律
  controlPoints: ['...'],  // 防治要点
  images: [],
  source: '...',
  updatedAt: 0
}
```

### 3.3 方案（规则推荐的输出）

```js
{
  id: '...',
  region: '...',
  crop: '...',
  growthStage: '...',      // 生育期
  weeds: ['...'],          // 目标杂草
  steps: [
    { order: 1, type: '封', detail: '...' },   // 封 = 土壤封闭处理
    { order: 2, type: '杀', detail: '...' }    // 杀 = 茎叶处理
  ],
  productIds: ['...'],     // 关联的除草剂 id
  source: '...',           // 来源（须可追溯）
  priority: 'eco'          // 排序依据：生态 > 低危 > 高危
}
```

### 3.4 用户本地配置（个人中心）

```js
{
  region: '',
  crops: [],
  favorites: [],   // 收藏的农药 / 杂草 / 方案 id
  history: []      // 浏览历史
}
```

**约定要点**：

- 所有用量、剂量类信息**必须可追溯到来源**，前端不得硬编码未经审核的内容
- `hazardLevel` 高危判定须引用权威名录，不可自行划定
- 字段名一旦确定不要随意改名
