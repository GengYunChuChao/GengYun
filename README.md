# 农识宝 · 农业智能识别小程序（前期准备阶段）

面向农民用户的微信小程序：**拍照识别作物病害**与**农药**，给出通俗易懂的处置建议与用法用量，并支持**中文语音播报**，降低识字与阅读门槛。

> **当前状态：前期准备（未开始功能开发）**
> 仓库只包含开发环境配置、协作规范与需求占位文档。页面与功能等策划案确定后开发，见 [`docs/需求规划.md`](docs/需求规划.md)。

## 技术选型（已定）

- **原生微信小程序**（WXML / WXSS / JavaScript），不引入构建工具与第三方 UI 库
- 理由：多人协作零构建成本，clone 后用微信开发者工具直接打开即可运行；拍照、选图、音频播放等能力原生 API 支持最完整
- **不需要 Node.js**：工程无 npm 依赖、无构建步骤
- 目录约定：小程序源码位于 `miniprogram/`，由 `project.config.json` 的 `miniprogramRoot` 指向

## 快速开始

1. 安装工具（Git 与微信开发者工具），详见 [`docs/环境准备.md`](docs/环境准备.md)
2. 克隆仓库

   ```bash
   git clone <仓库地址>
   cd challenge_cup
   ```

3. 微信开发者工具 → 「导入项目」→ 目录选择仓库根目录
   - AppID：可先用测试号，或填入自己的小程序 AppID
   - 后端服务：选择「不使用云服务」
   - 开发模式：选择「小程序」（**不要**选「多端应用」，本项目为纯微信小程序）
4. 编译后应看到「工程初始化完成」状态页，说明环境正常
