# 仅用户本人可做的控制台清单

2026-10-12，Refs #25。配套 [README.md](README.md) / [verify-vpc-linkage.md](verify-vpc-linkage.md) / [connection-verification-prep.md](connection-verification-prep.md)。

**为什么单列**：以下动作需要微信扫码身份、腾讯云账号登录、付费或平台侧授权，**都属于 AI 无条件不可执行的范畴**（无凭据、且被明确禁止购买/开通/扩权/生产变更）。请逐项打勾；打勾即代表**你本人**已执行并核对，任何人不得代勾、代执行、代声称完成。

规则提醒：真实 UIN、密钥、口令、内网 IP 等只写入仓库外私密目录（本仓库既有约定 `E:\GengYunPrivate`），**不要**贴到聊天、issue、PR 或任何仓库文件。

## A 账号与归属（判定项 ①，最高优先级）

- [ ] **A1 确认登录的是目标小程序/公众号**
  - 前置：能在微信客户端扫码。
  - 操作：打开 `https://cloud.weixin.qq.com/cloudrun/` 扫码，在账号选择界面选择**本项目对应的小程序/公众号**。
  - 完成验证：环境下拉中能看到别名 `prod`、环境 ID `prod-d1g6qe87c4f2d7061`。
- [ ] **A2 记录"云托管背后绑定的腾讯云账号"UIN**
  - 前置：A1 完成；有「环境设置」查看权限。
  - 操作：「设置 → 环境设置 → 基础信息」→ 点击「**充值与账单**」→ 记录跳转后腾讯云账号的账号 ID（UIN）。**只记入私密目录**。
  - 完成验证：私密目录里有一行"云托管绑定账号 UIN = ..."，并注明记录日期与来源入口。
- [ ] **A3 记录 `gengyun-vpc` 所属账号的 UIN 与地域**
  - 前置：能用**创建该 VPC 时使用的腾讯云账号**登录。
  - 操作：登录[腾讯云账号信息](https://console.cloud.tencent.com/developer) 记录 UIN；到 [VPC 控制台](https://console.cloud.tencent.com/vpc) 把地域切到**上海**，确认能看到 `gengyun-vpc`（`vpc-h33f1h5a`）及其子网。
  - 完成验证：私密目录有"VPC 归属账号 UIN = ... / 地域 = 上海 / 子网数 = 1"。
- [ ] **A4 比对两个 UIN 并落纸结论**
  - 前置：A2、A3 完成。
  - 操作：在私密目录内比对（**不要把 UIN 写进仓库**）。
  - 完成验证：得到明确三选一结论——"同一账号" / "不同账号" / "无法取得"。并把结论（仅结论、不含 UIN）回填到本单的核验记录。
- [ ] **A5 若结论为"不同账号"：做决策，但**不要**直接换绑**
  - 前置：A4 = "不同账号"。
  - 操作：阅读官方说明——"更换绑定的腾讯云账号，**必须销毁当前所有环境且无法恢复**"（[账号说明](https://developers.weixin.qq.com/miniprogram/dev/wxcloudservice/wxcloudrun/src/guide/account/)）。结合"不得重建既有网络"的约束，记录你的决定（接受/暂缓/改用其他方案），**不要**在未决策前删除任何环境。
  - 完成验证：本单核验记录中出现"账号不一致 → 决策：<你的选择>（未执行破坏性操作）"。
  - ⚠️ 该分支属**破坏性不可恢复**操作，AI 不会执行，也不建议在任何核验阶段执行。

## B 地域（判定项 ②）

- [ ] **B1 确认环境地域为上海**
  - 前置：A1 完成。
  - 操作：「设置 → 环境设置 → 基础信息」查看"环境部署地域"。
  - 完成验证：显示上海；若显示其他值，记录实际值并停止推进。
- [ ] **B2 确认腾讯云侧资源都在上海**
  - 前置：A3 完成。
  - 操作：腾讯云控制台地域切换到上海，逐一确认 VPC/子网（以及将来的 CVM/PostgreSQL）都在上海。
  - 完成验证：清单式记录"上海：VPC ✓ / 子网 ✓ / CVM □ / PostgreSQL □"（后两项待 E 组）。

## C 互联能力与授权（判定项 ③④⑤）

- [ ] **C1 确认自己的微信侧角色**
  - 前置：A1 完成。
  - 操作：「设置 → 权限设置」`https://cloud.weixin.qq.com/cloudrun/settings/privilege` 查看自己的角色（云托管管理员 / 环境管理员 / 开发者）与被勾选权限。
  - 完成验证：记录自己的角色；若不足，由**管理员**按需勾选（不要申请核验以外的权限）。
- [ ] **C2 到新版入口查看是否有 VPC/子网选项**
  - 前置：C1 完成；目标服务已存在。
  - 操作：服务管理 → 服务列表 → 目标服务 →「**服务设置 → 私有网络设置**」。
  - 完成验证：如实记录三种之一——"有 VPC/子网选择项" / "入口存在但无选项" / "无此入口"，并**抄下页面提示原文**。
- [ ] **C3 到旧版入口记录资源互联授权状态**
  - 前置：C1 完成。
  - 操作：「设置 → 环境设置 → **资源互联**」查看授权状态（官方自查指南第 2 步）。
  - 完成验证：记录授权状态原文与是否有资源包/购买提示。**此步只读，不点购买**。
- [ ] **C4 若需要启用私有网络：由你本人启用并选 VPC/子网**
  - 前置：C2 有选项；A4 结论为"同一账号"**或**已按 A5 决策改用同一账号下的上海 VPC。
  - 操作：在「服务设置 → 私有网络设置」启用并选择 VPC 与子网后保存。**注意：保存后服务会发布新版本**，属生产变更，请自行选择时间窗并准备好回滚（版本回退）。
  - 完成验证：服务设置显示已配置 VPC/子网；版本列表出现新版本；新版本实例的 VPC 配置中可见"额外新增的弹性网卡及其对应 IP 地址"。
- [ ] **C5 关于"是否必须购买资源包"的决策（明确**不**由 AI 执行付费）**
  - 前置：C2/C3 结论已记录。
  - 事实（官方原文）：新版机制下"**当前无需购买服务资源包或互联资源包，也可以直接使用服务对接腾讯云私有网络 VPC 能力**"；同一页旧段仍写"需业务购买互联资源包"；"服务资源包（原互联资源包）"售价 **36 元**、有效期 3 个月、**环境级**、**一次性不可续费**、**不支持退款**。
  - 操作：**先完成 A/B 两组的账号与地域判定**。若 C2 无选项而 A4 结论为"不同账号"，购买资源包**不能**解决该问题（原因与购买无关）。任何购买决定须你本人明确授权后自行执行。
  - 完成验证：本单核验记录中出现"是否购买：否 / 是（日期）"，且注明依据；**不得**出现"已买即已解决"这类未验证表述。
- [ ] **C6 若控制台出现"服务角色/授权"提示**
  - 前置：遇到该类提示。
  - 操作：抄下提示原文，再决定是否授权。
  - 完成验证：记录提示原文与你的决定。说明：微信云托管/腾讯云开发官方文档中**未找到**"必须先授权某个云托管服务角色才能绑定 VPC"的依据，因此**不要**凭猜测创建角色或策略。
- [ ] **C7 检查环境状态（冻结/欠费）**
  - 前置：无。
  - 操作：看环境与服务的状态、以及「充值与账单」的余额/欠费提示。
  - 完成验证：记录"未冻结/未欠费"或实际异常。官方规则：30 天无请求调用会冻结环境；欠费超 7 天删除环境。

## D 权限与凭据（判定项 ④）

- [ ] **D1 需要只读核验时，建受限子账号并只授读动作**
  - 前置：确定要在**哪个腾讯云账号**下核验（A4 结论）。
  - 操作：在该账号的 [CAM 控制台](https://console.cloud.tencent.com/cam) 建子账号，只授读动作（候选：`DescribeVpcs`、`DescribeSubnets`、`DescribeSecurityGroups`、`DescribeSecurityGroupPolicies`、`DescribeVpcPeeringConnections`、`GetCallerIdentity`）。
  - 完成验证：子账号列表与策略可读；**不要**授管理员或写权限。
- [ ] **D2 私密交接该只读凭据**
  - 前置：D1 完成。
  - 操作：把凭据写入仓库外私密目录（`E:\GengYunPrivate` 约定），**不要**贴聊天/issue/PR/仓库。
  - 完成验证：凭据文件在仓库外且被忽略；仓库 diff 中无任何密钥字样。
- [ ] **D3 可选：生成微信云托管 CLI 密钥（需管理员扫码）**
  - 前置：决定用 CLI 做只读核验。
  - 操作：「设置 → CLI 密钥」`https://cloud.weixin.qq.com/cloudrun/settings/other` 生成并私密保存。
  - 完成验证：CLI 能 `wxcloud env:list --json` 并返回含 `prod-d1g6qe87c4f2d7061` 的条目（判读见 [verify-vpc-linkage.md](verify-vpc-linkage.md) B1）。

## E 资源就绪（CVM / PostgreSQL / 安全组）

- [ ] **E1 核实 CVM 是否已购买/创建（用户明确"尚未核实"）**
  - 前置：A4 结论已知（决定在哪个账号、哪个 VPC 下建）。
  - 操作：在腾讯云 CVM 控制台确认是否已存在目标实例；如无，由你决定是否购买与规格（**付费决策**）。
  - 完成验证：记录"已存在/不存在"，以及（若存在）地域=上海、是否在 `gengyun-vpc`、内网 IP、状态=运行中。
- [ ] **E2 确认 PostgreSQL 监听内网可达地址**
  - 前置：E1 存在。
  - 操作：在 CVM 上确认监听 `0.0.0.0:5432`（或私网 IP），而非仅 `127.0.0.1`。
  - 完成验证：`ss -lntp` 输出中 5432 的监听地址符合预期。
- [ ] **E3 安全组放通 5432，来源限定为云托管实例所在子网网段**
  - 前置：C4（或已有等价配置）已完成，知道云托管实例将使用哪个子网。
  - 操作：在目标 CVM 的安全组入站规则中放通 `TCP:5432`，来源填该**子网网段**（或该 VPC 网段）。官方自查指南第 6 步即核对"安全组是否有入站规则屏蔽了服务内网 IP 所在的网段"。
  - 完成验证：规则可读，来源不是 `0.0.0.0/0`；记下规则摘要。
- [ ] **E4 确认子网空闲 IP 与弹性网卡配额充足**
  - 前置：C4 前/后均可。
  - 操作：在 VPC 控制台查看子网可用 IP；在[配额中心](https://console.cloud.tencent.com/limitation) 查看上海地域的弹性网卡/私网 IP 配额与已用值。
  - 完成验证：记录可用 IP 数 ≥ 预期实例上限。官方警告：IP 不足会导致实例无法正常启动。
- [ ] **E5 子网 ACL 未阻断**
  - 前置：无。
  - 操作：查看该子网的网络 ACL 入站/出站规则。
  - 完成验证：无针对 5432 的拒绝项（默认放通即可）。

## F 验证执行许可

- [ ] **F1 逐项核对连接验证门禁，并明确许可**
  - 前置：A–E 全部完成。
  - 操作：对照 [connection-verification-prep.md](connection-verification-prep.md) 第 2 节 G1–G11 逐条打勾；缺项不勾。
  - 完成验证：G1–G11 全绿后，你再明确授权"可以执行只读探活"；未获授权时，验证命令**一律不执行**。
- [ ] **F2 由你决定并记录只读探活的执行人与时间窗**
  - 前置：F1 全绿。
  - 操作：指定执行人（你本人或你授权的执行者）、时间窗、以及允许执行的命令范围（方法 A/B/C）。
  - 完成验证：核验记录中出现"执行人 / 时间窗 / 允许范围"，且**不含**任何口令或 DSN。

- [ ] **G1 把结论写回仓库、把事实留在私密目录**
  - 前置：以上各项有结论。
  - 操作：仓库只写"判定项 ①–⑤ 的结论 + 观察到的提示原文 + 错误码 + 命令退出码 + 日期与基线 SHA"；UIN、密钥、口令、内网 IP、截图原图只留在私密目录。
